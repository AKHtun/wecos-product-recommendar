## Highlights

The first public release of **WEcoS Product Recommendar** — a suite of five
Distributor Lubricant Engineer (DLE) skills that produce verified equivalent
/ alternative recommendations across all the fluid product categories.

The suite is built around three design principles:

1. **Verified, not invented.** Every cited specification traces to a producer
   PDS / TDS / SDS. Background knowledge is not a fallback.
2. **Tiered, not single-pick.** Fleet recommendations default to
   **Standard + Upgraded** output so the end customer (and the DSR) sees
   the technical rationale for paying more.
3. **Chemistry-grounded for greases.** Grease is the highest-friction
   recommendation category (thickener, base oil, NLGI, additive, OEM
   approval all interact). The grease skill ships with a DIN 51502 /
   ISO 6743-9 designation decoder and the ExxonMobil 7×7 compatibility
   matrix baked in.

| # | Skill | Scope |
|---|---|---|
| 1 | **lubricant-recommender** | Engine oils, gear oils, hydraulic oils, compressor oils, turbine oils, refrigeration-compressor oils, PAG fluids, heat-transfer fluids |

| 5 | **grease-recommender** | Industrial, automotive, food-grade (NSF H1), marine, mining / heavy-load, electric-motor, refrigeration-compressor, central-lube, railway axlebox, high-temperature |

Each skill ships with `SKILL.md` (methodology + hard rules), `references/`
(verified PDS, supplier catalogs, SOP flow), `scripts/` (PDF rendering,
record appending, template building), `templates/` (report + Excel),
and `output/` (gitignored — generated artifacts).

## What's new in v1.0.0

### Methodology extensions (added July 2026)

- **§0b — Product currency check (mandatory).** Five-step verification that
  the cited SKU is current on the producer's PDS index before any
  recommendation. Catches the 2024-2026 wave of consolidations
  (e.g., Mobil Delvac MX ESP → Mobil Delvac Modern 15W-40 Full Protection).
- **§0c — Tiered Standard / Upgraded output.** Default fleet
  recommendation is two-tiered (Y standard + Y+ upgrade), not single-pick.
  Upgrade rationale is always technical (drop point, OEM approval set,
  drain interval) — never commercial.
- **§6 — Always-on warning matrix.** Six warning categories rendered in
  priority order: **over-greasing first → purge → base-oil-vs-NLGI →**
  vertical-mount NLGI 3 → water exposure → shelf-life advisory.
- **§11 — Reference-ledger integration.** DSR personal reference ledger
  (MEM-AUNG-YYYY-NNN format) cross-referenced on every recommendation,
  surfacing prior comparable cases.
- **§11b — DSR business email template.** Gemini-style
  `Subject: Product Recommendation _ <DDMMYY> - DLE` template with the
  project disclaimer verbatim.

### Customer-corrected hard rules

- **#7 — Currency check is mandatory** before any PDS citation
- **#8 — Tiered Standard + Upgraded output is default** (not single-pick)
- **#9 — Never hardcode shelf-life numbers** — varies by thickener
  chemistry, base oil, antioxidant, container, storage
- **#10 — Render all tables to fit user's display width** (no horizontal
  scroll)
- **#11 — Purging advisory = "till new grease exits drain plug"** — don't
  over-specify procedure
- **#12 — Vertical-mount = NLGI 3 preferred** (prevents gravity slumping);
  NLGI 1.5/2 acceptable
- **#13 — Shelf-life can include industry-standard range + supplier-check
  caveat**

## Known limitations

- **Regional availability** — Singapore / SEA coverage is strongest.
  EU, US, APAC (ex-Singapore) coverage is lighter and would benefit
  from local distributor data contributions.
- **CI / status checks** — No automated test suite yet. Smoke tests
  are manual (run each skill against a test incumbent in its `output/`
  folder). When CI is added, branch protection will gain a
  "require status checks" toggle.
- **Visual page outputs** — Mermaid pipeline diagrams live under
  `visual-page/` (currently non-skill output). Future releases may
  promote this to a proper skill.
